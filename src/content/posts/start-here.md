一篇文章的起点，可以是一个问题、一次尝试，也可以是今天新学到的一件小事。不必等到所有思路都完整了，先写下来，再慢慢整理。

## 从一个具体的问题开始

与其写一个很大的主题，不如先回答一个小问题：这件事为什么发生？我试过哪些办法？如果重新做一次，我会改变什么？

具体的问题让记录更容易开始，也让之后回看的人更容易理解上下文。

## 用 Markdown 保持简单

Markdown 让你专注于文字，也能清楚地表达结构。一个二级标题、一小段列表，通常就足够整理一篇笔记。

```markdown
## 今天的发现

这里是一段正文。可以用 **粗体** 强调关键词。

- 第一个观察
- 第二个观察
- 下一步想尝试的事
```

如果需要记录代码，也可以指定语言，让阅读更轻松：

```python
def keep_a_note(thought: str) -> str:
    return f"今天记下：{thought}"

print(keep_a_note("先开始，再完善。"))
```

## 留下可以继续的地方

不必每篇文章都给出完整答案。把暂时没有解决的问题单独列出来，下一次回来时，你就知道从哪里继续。

1. 写清楚背景和目标。
2. 记录过程中的关键选择。
3. 留下下一步的问题。

文字会随着理解一起生长。先留下一个起点，就已经很好。
